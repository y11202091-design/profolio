學習反思與總結

這門課對我來說是一場跨越技術門檻的冒險，總共涵蓋了四大核心部分：

  • 1. 使用 Monster Mash 及 Polycam 製作 3D 物件
  • 2. 使用 Google AI Studio 生成網頁遊戲
  • 3. 使用 GitHub 上傳與部署網頁
  • 4. 使用 Gemini 生成學習成果網站首頁

最終感悟：

我覺得用 Gemini 做網站其實並不難，雖然處理檔案存取時費了番功夫，但當我看到成果時真的很不可置信。想不到完全不會打程式的我，竟然可以完成！這讓我深信，先前的努力都是值得的。
