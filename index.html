學習反思與總結

這門課程是一次完整的數位轉型體驗，涵蓋了四大技術領域：

  • 使用 Monster Mash 及 Polycam 製作 3D 物件
  • 使用 Google AI Studio 生成網頁遊戲
  • 使用 GitHub 上傳與部署網頁
  • 使用 Gemini 生成學習成果網站首頁

最終感悟：

我覺得用 Gemini 做網站其實並不難，只是把檔案存進去很麻煩，也因此費了番功夫。但當我看到自己成果時，真的很不可置信，想不到完全不會打程式的我，竟然可以完成！我覺得之前的努力是值得的。
